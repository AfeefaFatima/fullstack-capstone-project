# GiftLink User Stories

## Backlog / New / Icebox / Technical Debt

1. **Backlog** — As a donor, I want to create an item listing so that someone else can reuse my household item.
2. **Backlog** — As a visitor, I want to browse all available items so that I can find useful free products.
3. **New** — As a visitor, I want to search by keyword so that I can quickly locate an item.
4. **New** — As a visitor, I want to filter by category so that results are easier to navigate.
5. **Backlog** — As a user, I want to open an item detail page so that I can see its description, condition and location.
6. **Backlog** — As a registered user, I want to comment on an item so that I can communicate with the community.
7. **New** — As a user, I want to register and log in securely so that my account is protected.
8. **New** — As a user, I want to edit my profile so that my contact information stays current.
9. **Icebox** — As a user, I want to save favorite items so that I can revisit them later.
10. **Icebox** — As a user, I want notifications when a matching item is posted.
11. **Technical debt** — As a developer, I want automated CI checks so that broken builds are detected before merge.
12. **Technical debt** — As a developer, I want Docker Compose to standardize local setup.
